微軟在 GitHub 上開了一門免費的「AI Agents for Beginners」課程，並提供繁體中文翻譯，從「什麼是 AI 代理」一路講到正式上線要注意的事。這篇整理課程的內容架構，也給初學者一份讀法建議。

- **適合誰**：他說是會一點 Python、用過 ChatGPT 之類工具，想知道「AI 代理」到底怎麼運作的人。但其實不會也沒關係。
- **解決什麼問題**：「AI Agent」這個詞到處都是，卻很少有人系統性地講它由哪些概念組成。這門課把概念整理成一組設計模式，逐一說明。
- **不適合誰**：想要一份「照著做就能跑」的產品教學，或者完全只用Ai聊天人。這兩種人會覺得後半段吃力。

## 這門課在教什麼

課程拆成一系列短課，每課各講一個主題，通常附有文字講義和 Python 範例程式（我覺得看不看無所謂，看不懂就叫Ai解釋給你聽）。整體可以分成四個部分。

**第一部分：認識代理與框架。** 先說明 AI 代理和一般聊天機器人的差別：代理不只回答問題，還會自己判斷下一步、呼叫工具、完成任務。接著介紹幾個建構代理的框架。課程出自微軟，所以範例以微軟自家的工具與服務為主，例如 Semantic Kernel、AutoGen。

**第二部分：核心設計模式。** 這是全課最有價值的部分，講的是做代理時一再出現的幾種做法：

- **工具使用**：讓模型去呼叫外部函式或 API，例如查天氣、查資料庫。
- **Agentic RAG**：模型不只被動接收檢索結果，還會主動決定要查什麼、查得夠不夠。
- **規劃**：把一個大目標拆成多個步驟，再依序執行。
- **多代理協作**：讓幾個各有分工的代理互相配合。
- **後設認知**：讓代理檢查自己的推理和結果，必要時修正。

**第三部分：可信賴與上線。** 這部分談代理的安全性、如何避免被誤用，以及放到正式環境後要怎麼觀察、評估和控制成本。很多入門教材會跳過這些問題，這門課有專門處理。

**第四部分：較新的主題。** 這個課程庫持續更新，後來陸續加入代理之間的溝通協定（例如 MCP）、上下文工程、記憶機制等主題。

## 值得推薦嗎

值得看看，尤其適合想打好觀念基礎的初學者。它的優點是用「設計模式」當主軸，而不是用某個框架的 API 當主軸。框架幾個月就會改版，但「工具使用」「規劃」「多代理」這些概念不會很快過時（至少能撐過2027）。學會這些概念以後，換成 LangChain 或其他工具，你也知道自己在做什麼。

要注意的是它的微軟色彩。範例環境和框架大多綁在微軟生態系上。把它當成「用微軟工具示範的通用觀念」來讀，就不會被侷限住。

## 給初學者的讀法建議

**先讀前三課，再決定要不要動手。** 前幾課以概念為主，讀完你就能判斷自己是想深入開發，還是只想了解這個領域。只想了解的話，把整門課的講義讀過一遍就有收穫，不必每課都跑程式。

**把「工具使用」當成第一個動手的主題。** 代理的其他能力幾乎都建立在「呼叫工具」上。先把這一課的範例跑通，再往下讀會順很多。

**讀設計模式時，自己想一個生活化的例子。** 例如「幫我安排一趟三天的旅行」。拿這個例子去對照每一課：它需要哪些工具？要怎麼規劃步驟？需不需要多個代理分工？用同一個例子貫穿全課，比單純記名詞有效。

**多代理和後設認知可以晚點再讀。** 這兩課比較抽象，前面的基礎不穩時讀起來會很虛。等你自己做過一個簡單的代理、遇到它出錯或做得不夠好，再回來讀，會比較有感。

**別跳過「可信賴」和「上線」那兩課。** 這兩課看起來不刺激，卻是代理實際使用時最常出問題的地方。代理能自己行動，一旦出錯，影響通常比聊天機器人回錯一句話大得多。

**中英對照著看。** 繁中翻譯降低了入門門檻，但專有名詞最好記住英文原文，之後查資料、看其他框架的文件才接得上。
