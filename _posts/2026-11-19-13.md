因為AI帶動了CLI普及，整合Harness的新世代Terminal又被追棒了。真是活久見呀！近40年前玩BBS的工具；在Web出現之後就逐漸消失的東西，忽然又佔據了桌面。這個在十年前，不，五年前跟我說會發生，我是不信的。

這篇說明 Herdr、Cmux這類工具被關注的原因：它把「登入哪台機器」和「看哪個 agent 在做什麼」拆成兩件事。它也把跨機器的 coding agent 管理，從一條條 SSH 連線改成一個集中的介面。

- **它為什麼出現**：因為要同時跑好幾個 coding agent（Claude Code、Codex、opencode 等），而且分散在筆電、桌機、租來的伺服器上時，最麻煩的是找出哪個卡住了、在等你回答，以及連線一斷工作是否跟著中斷。
- **它解決什麼**：終端機交給背景常駐的服務託管，agent 不會因為你闔上筆電或斷網而停下。它也會判讀每個窗格，把 agent 標成工作中、卡住或閒置。
- **關鍵轉變**：從「先 SSH 進遠端，再在那台機器上開介面」，變成「在本機開一個介面，用 SSH 把多台機器納進來」。
- **適用情境**：多台機器、多個平行任務需要一座控制塔時，這種架構最有價值。如果只是專心處理單一台伺服器，直接 SSH 進去仍然是最直接的做法。

## 通道和介面是兩回事

很多人講「連到遠端」時，把連線方式和操作介面混在一起。比較清楚的看法是：SSH 是通道，負責把你的按鍵安全送到遠端，再把輸出傳回來。TUI（終端機使用者介面）是介面，負責把狀態整理成你看得懂的畫面。

有些說法會搬出 OSI 七層模型，把 SSH 放在會話層、TUI 放在應用層。這種對應其實不太精確，一般多把 SSH 視為跑在 TCP 上的應用層協定。不過它想表達的重點沒錯：通道和介面是組合關係，不是二選一。真正值得討論的是兩者怎麼組合。

## 兩種組合，兩種體驗

傳統做法是先 SSH 到遠端主機，再在那台機器上啟動 TUI。介面跑在遠端，看到的也只有那台機器的東西。想同時照看另一台機器，就得再開一個連線或視窗。每台遠端機器都要各自裝好、設定好工具。

Herdr 走的是另一條路。它的官網寫得很直白：你的筆電、樓上的桌機、租來的伺服器，用 SSH 加進來之後（例如 `herdr machine add workbox`），那些機器上的工作區和 agent 會跟本機的並排顯示。切換機器不用另開 client，斷線了它們也會繼續工作。

差別不只在少開幾個視窗。在傳統做法裡，你管理的單位是「一條連線」。在 Herdr 裡，你管理的單位變成「一個正在跑的 agent」，它在哪台機器上反而退到背景。

至於畫面延遲，有分析認為本機介面可以在本機渲染，只有狀態和指令走 SSH，因此在高延遲網路下比較順。這是依架構所做的推論，官網並沒有談到渲染細節，實際效果還要看使用情況。

## 為什麼這對跑 agent 特別重要

讓工作在斷線後繼續存活，本來就有 tmux、screen 這類老工具可以做到。Herdr 比較不同的地方在於，它是為 coding agent 設計的。

第一，它不是一個要一直開著的程式，而是背景伺服器，終端機住在裡面。官網說，闔上筆電或網路中斷時 agent 會繼續工作；機器重開後，Herdr 會把版面還原並恢復各個 session。它示範畫面裡的一句話很有代表性：一個資料回補任務已經跑了六個小時，完全不受你的筆電影響。

第二，它會讀每個窗格，把 agent 標成工作中、卡住或閒置。某個 agent 停下來等你回答時，它會主動告訴你。同時跑四、五個 agent 的人應該都經歷過一格一格去找「是誰在等我」，這個功能正是衝著這種痛點來的。

第三，它的 CLI 和 socket API 也讓 agent 自己操作。agent 可以分割窗格、啟動彼此、互相下指令，也能等到另一個 agent 真的卡住再行動，不必亂送按鍵碰運氣。這代表介面不只給人看，也成為 agent 之間協作的平台。

第四，它不包裝也不取代你現有的工具。官網列出 Claude Code、Codex、Cursor、opencode、Grok、Copilot 等，宣稱開箱即可偵測 22 種 agent。它只接管這些工具的終端機，提供 macOS、Linux、Windows 共用的單一執行檔。

這類工具反映出一個趨勢：當開發者的工作從「自己敲指令」變成「看顧一群 agent」，終端機管理工具的重心也從維持連線，轉向掌握每個 agent 的狀態。


## 終端也不只是終端

以前BBS是純文字，就真的是純文字，文字的後面沒藏一堆東西。當年Modem從9.6k發展到56K，已經是電話線的極限，所以講求的是速度輕薄。現在的終端等於是包了一整套的TUI，看起來是純文字，但那只是顯示出來的部份，沒顯示在畫面上的比顯示出來的多數倍。網路快了，內容也肥了，但必須說真是懷念的世界啊。
