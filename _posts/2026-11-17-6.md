Claude Code mod 是裝在 Claude Code 這個程式上的小改裝，能在畫面上多加資訊，或在某些時間點替你多做一件事。這篇用幾個實際例子說明它在哪裡運作、什麼時候發揮作用、怎麼開始用，以及它跟 Skill、MCP 的差別。

- **它在哪裡**：在 Claude Code 程式本身，也就是你眼前跟 Claude 對話的那個視窗。
- **它什麼時候出手**：有的一直顯示在畫面上，有的在某件事發生的那一刻才動作，例如你貼上圖片時、Claude 打開檔案時，或指令執行之前。
- **它解決什麼**：Claude Code 原本的畫面是固定的。mod 讓你看到原本看不到的東西，例如用了多少額度、Claude 正在動哪個檔案，也能在關鍵時刻替你把關。
- **它不做什麼**：mod 不會讓 Claude 變聰明，也不會讓 Claude 連上新的服務。那分別是 Skill 和 MCP 的工作。

## 先搞清楚 Claude Code 是什麼

Claude Code 是 Anthropic 推出的程式，讓 Claude 在你的電腦上幫忙寫程式、讀檔案、執行指令。它可以在終端機（黑底打字的視窗）、桌面版 App 或 VS Code 編輯器裡使用。

mod 就是加裝在這個程式上的小外掛。你可以把 Claude Code 想成一間辦公室，Claude 是在裡面工作的助手，mod 則是你在辦公室裡加裝的東西：牆上的電子看板、桌上的提醒燈，或門口的一道檢查關卡。

mod 需要 Claude Code 2.1.287 以上的版本，預設就能使用，不用另外開啟任何設定。

## mod 什麼時候發揮作用：看例子最清楚

社群整理的清單 [awesome-claude-code-mods](https://github.com/karanb192/awesome-claude-code-mods) 精選了七個日常好用的 mod。依照它們「什麼時候出手」來分，比較容易看懂。

**一直開著，隨時讓你看到狀況**

- **flightdeck**：一塊即時看板，顯示對話用了多少容量、花了多少錢、Claude 申請了哪些權限，以及它分派出去的小幫手在做什麼。它只負責顯示，不會改變 Claude 的任何動作。
- **lot-map**：在對話旁邊畫一張地圖，Claude 每做一個動作，地圖上就有一個點亮起來。外圈會隨著對話容量用掉多少慢慢填滿，讓你知道這次對話快滿了。要在桌面版或 VS Code 裡才看得到圖，在終端機裡則改用文字顯示。
- **prompt-rail**：把你問過的問題排成一條側欄，想回頭看某個問題時點一下就能跳回去。

**某件事發生的那一刻**

- **image-view**：在你**貼上圖片的那一刻**，先在輸入框上方顯示縮圖，讓你送出前確認貼對了。它需要特定的終端機程式，例如 Ghostty 或 kitty。
- **filetree**：顯示專案的檔案清單，**Claude 打開或修改某個檔案的那一刻**，該檔案就會被標亮。你點選檔案，就能直接告訴 Claude 要處理哪一個。在終端機裡使用時要開全螢幕，而且視窗要夠寬。
- **prismantis**：**Claude 回覆的時候**，把表格、程式碼和圖表直接畫成好讀的樣子，並附上複製按鈕。它預設會讓每次提問多用大約 190 個 token（Claude 的計費單位），這項功能可以關掉。

**你不在的時候**

- **cache-tax**：Claude 會暫存前面的對話內容，讓你接著問的時候比較便宜，但放太久這份暫存就會失效。這個 mod 會在**你休息離開時**讓暫存保持有效。如果暫存已經失效，它會在你送出下一個問題前先擋一次，告訴你這次大概要花多少。要注意的是，維持暫存本身也會花費額度。

除了這些，mod 也能做到「指令執行前先檢查一次」，或在對話旁邊開一個瀏覽器。

這些例子有個共同點：它們都發生在 Claude Code 這個程式裡，改的是你看到什麼、在什麼時間點多做一道動作。

## 怎麼開始用

1. **找**：到[線上目錄](https://mods.aidojo.si/)用名稱或想做的事搜尋。也可以先裝一個叫 mod-finder 的 mod，再直接問 Claude：「幫我找一個能協助 code review 的 mod」。
2. **看權限**：目錄裡每個 mod 都標了它能讀哪些東西、能改哪些東西、能不能執行程式、會不會上網。
3. **照說明安裝**：每個 mod 的頁面都有安裝說明。也要看它支援哪裡，有的只能在桌面版用，有的需要特定終端機。

如果找不到想要的，也可以請 Claude 幫你做一個。Anthropic 有官方入門指南，社群也有專門教 Claude 做 mod 的 Skill，例如 claude-mods-skill。

## 跟 Skill、MCP 差在哪

這三樣都算是「擴充 Claude」，差別在於它們**作用在哪裡、什麼時候出手**。延續前面辦公室的比喻：

| | 作用在哪裡 | 什麼時候出手 | 比喻 |
|---|---|---|---|
| **mod** | Claude Code 程式本身、你眼前的畫面 | 一直顯示，或某件事發生的那一刻 | 改裝辦公室：加看板、裝提醒燈、設檢查關卡 |
| **Skill** | Claude 的做事方法 | Claude 判斷這件工作需要那份知識時 | 給助手一本工作手冊 |
| **MCP** | Claude 跟外部服務之間 | Claude 需要去外面拿資料或操作其他系統時 | 給助手公司各系統的帳號 |

舉個例子會更清楚。前面提到的 claude-mods-skill 是一份「教 Claude 怎麼做 mod」的工作手冊，它本身是 Skill，Claude 照著它做出來的成品才是 mod。

MCP 則是讓 Claude 連到外面的服務，例如公司的工單系統或雲端文件，讓它多了可以操作的對象。

三者可以同時使用：用 MCP 讓 Claude 讀公司的工單，用 Skill 讓它照團隊規範寫程式，再用 flightdeck 在旁邊盯著花了多少錢。

## 安裝前多看一眼

mod 是會在你電腦上實際運作的程式，而這份清單收錄了 8,769 個 mod，品質不一。有兩點要記得：

- **這是社群整理的目錄，不是 Anthropic 的官方商店。** 有同時收錄在 Anthropic 官方外掛目錄裡的 mod，網站會特別標出來。
- **檢查通過不等於安全。** 目錄只檢查程式內容，沒有實際執行它，所以無法保證實際運作時沒問題。

初學者可以先從精選清單裡、只負責「顯示」的 mod 開始，例如 flightdeck。會改檔案、執行指令或上網的 mod，等你比較清楚它在做什麼再裝。

想一想，Mod、 Skill、MCP，能不能很清楚的講得出來，這些有什麼不同？
